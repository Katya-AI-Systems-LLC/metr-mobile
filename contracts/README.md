# METR Smart Contracts (contracts/)

Каталог `contracts/` содержит набор смарт‑контрактов (Solidity) для Web3‑части METR: токены, NFT‑достижения, DAO‑голосование и блокчейн‑аудит действий команды.

## Контракты

- `METRToken.sol` — основной токен METR:
  - ERC‑совместимый токен для внутренней экономики (мотивация, награды, стейкинг);
  - может использоваться для governance и платёжных сценариев.

- `METRAchievements.sol` — NFT‑достижения:
  - выпуск невзаимозаменяемых токенов за достижения команды и участников;
  - поддержка метаданных и редких достижений.

- `METRDAO.sol` — DAO‑управление:
  - механика голосований по предложениям (proposals);
  - связь с METRToken для взвешенного голосования.

- `BlockchainAuditTrail.sol` — блокчейн‑аудит действий:
  - неизменяемая история событий и решений команды;
  - цепочка хэшей, роли аудиторов/админов, проверки целостности.

- `EmotionalBlockchain.sol` — "эмоциональный" блокчейн:
  - концептуальный контракт для записи агрегированных эмоциональных показателей команды;
  - может использоваться совместно с AI‑аналитикой для мониторинга культуры и настроения.

## Связь с приложением

- `app/web3/Web3Manager.ts` — основной клиент к этим контрактам (через Web3‑провайдеры / WalletConnect).
- `app/gamification/*` и `app/productivity/*` — используют NFT/токены/DAO для геймификации и управления.
