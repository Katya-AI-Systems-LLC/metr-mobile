## 🎯 **USAGE EXAMPLES**

### Initialize METR:
```typescript
import {initializeMETR} from './app/core/METRInitializer';

// Initialize all features
await initializeMETR();

// Or initialize selectively
await initializeMETR({
  enableAI: true,
  enableWeb3: true,
  enableARVR: false,
  enableQuantum: true,
});
```

### Use Unified API:
```typescript
import METR from './app/core/METRIntegration';

// Access AI features
const assistant = METR.AI.personal;
const response = await assistant.processQuery("What's my schedule today?");

// Access Web3 features
const web3 = METR.Web3.manager;
await web3.connectWallet();

// Access UI features
const voiceUI = METR.UI.voice;
await voiceUI.startListening();

// Access Branding
const branding = METR.Branding;
const slogan = branding.getSlogan(); // "Measure Your Team's Potential"
```

### Use Logo Component:
```typescript
import {METRLogo} from './app/components/branding/METRLogo';

// Full logo
<METRLogo size={48} variant="full" color="primary" />

// Icon only
<METRLogo size={32} variant="icon" color="secondary" />

// With text
<METRLogo size={40} variant="text" color="accent" />
```
