## 1. Происхождение проекта

- Проект **METR (Modern Enterprise Team Revolution)** является **производным** от проекта **Mattermost Mobile**, распространяемого по лицензии **Apache License 2.0**.  
- Оригинальные файлы и компоненты, поставляемые Mattermost, сохраняют исходную лицензию и атрибуции.

В корне репозитория:

- `LICENSE.txt` — текст Apache License 2.0 от Mattermost, Inc.  
- `NOTICE.txt` — список сторонних компонентов и атрибуций.

Любое использование, модификация и распространение METR должно учитывать требования Apache 2.0, описанные в `LICENSE.txt`.

Помимо исходного кода Mattermost Mobile, в репозиторий добавлен значительный объём новых модулей и документации, включая (но не ограничиваясь):

## 3. Сохранение лицензии и атрибуций

При форке, модификации или распространении METR необходимо:

1. **Сохранить `LICENSE.txt`** без удаления или искажения текста Apache License 2.0.  
2. **Сохранить `NOTICE.txt`**, добавляя свои атрибуции (при необходимости) согласно разделу 4(d) Apache License 2.0.  
3. **Помечать изменённые файлы** (см. п. 4(b) Apache License 2.0) явным указанием того, что они были модифицированы.  
4. При добавлении собственных модулей —
   - либо использовать Apache 2.0;  
   - либо иную совместимую лицензию, чётко отражённую в заголовке файла.

METR не изменяет условий Apache 2.0, а расширяет проект дополнительным функционалом в рамках той же лицензии.
