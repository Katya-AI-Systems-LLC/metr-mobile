# METR UI Subsystem (app/ui)

Каталог `app/ui/` содержит высокоуровневые модули пользовательского интерфейса METR, отвечающие за адаптивность, жесты, темы, микровзаимодействия, голос и тактильную отдачу.

## Файлы и назначение

- `AdaptiveUI.ts` — адаптивный UI: подстраивается под предпочтения пользователя, контекст (время суток, локация, активность) и устройство, реорганизует компоненты и быстрые действия.
- `DynamicThemes.ts` — динамические темы: смена цветовых схем по времени суток, контексту, активности и системным настройкам, плавные анимации перехода тем.
- `MicroInteractions.ts` — микро‑анимации и эффекты: анимации кнопок, карточек, переходов, состояний загрузки и успеха/ошибки.
- `GestureNavigation.ts` — управление жестами: свайпы, пинч, ротейт, пан, много‑пальцевые и edge‑жесты, связанные с действиями навигации.
- `SmartContextualMenus.ts` — умные контекстные меню: AI‑подсказки действий, меню по контексту выделения, времени, задачам и истории действий.
- `HapticFeedback.ts` — расширенная тактильная отдача: паттерны вибрации для жестов, кликов, успеха/ошибок, игровых сценариев.
- `VoiceUI.ts` — голосовой интерфейс: обработка голосового ввода, триггеры для голосовых команд и взаимодействие с AI‑ассистентом.
- `ForceTouch.ts`, `ForceTouchHandler.ts` — заготовки для 3D Touch / Force Touch сценариев и обработки силы нажатия (поддержка будет зависеть от платформы и девайса).

## Связь с другими подсистемами

- Модули UI активно взаимодействуют с:
  - `app/ai/*` — для AI‑подсказок, контекстной аналитики и ассистентов.
  - `app/theme/metrTheme.ts` и компонентами glassmorphism для визуального стиля.
  - `app/sync/*` и `app/computing/*` — для отображения состояния синхронизации, офлайн/edge‑режимов.
