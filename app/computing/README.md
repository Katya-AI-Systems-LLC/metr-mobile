# METR Edge Computing (app/computing)

Каталог `app/computing/` содержит подсистему edge‑вычислений и распределения задач между устройствами.

## Файлы и назначение

- `EdgeComputing.ts` — ядро edge‑фреймворка METR:
  - описывает **edge‑узлы** (мобильные девайсы, планшеты, edge‑серверы) и их способности (CPU, память, GPU, сеть, датчики);
  - реализует **обнаружение узлов** (Bluetooth/Wi‑Fi/mesh, в реальном проекте через платформенные модули);
  - управляет **очередью задач** (AI inference, analytics, data‑processing, rendering, encryption);
  - распределяет задачи по узлам с учётом загрузки, ограничений по latency, батарее и предпочтений (local vs remote);
  - поддерживает **кластеризацию**, балансировку нагрузки и распределённые модели (data/model‑parallel).

## Связь с другими подсистемами

- `app/ai/*` — AI‑модули могут выносить тяжелые вычисления на edge‑узлы.
- `app/sync/*` — синхронизация состояния и результатов задач между устройствами.
- `app/ui/*` — визуализация метрик edge‑кластера, прогресса задач и health‑состояния.

Подробная концепция edge‑вычислений описана в:
- `docs/MODERNIZATION_CONCEPT_2025.md` (раздел Mobile‑First / Edge Computing)
- `FINAL_IMPLEMENTATION_STATUS.md` (соответствующие секции).
