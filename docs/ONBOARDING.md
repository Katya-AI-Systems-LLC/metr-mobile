# Onboarding Guide для METR

## Welcome!

Добро пожаловать в команду METR! Это руководство поможет вам начать работу.

## First Steps

### 1. Setup Development Environment

- [ ] Установите Node.js 18+
- [ ] Установите React Native CLI
- [ ] Установите Android Studio (для Android)
- [ ] Установите Xcode (для iOS)
- [ ] Установите Git

### 2. Clone Repository

```bash
git clone https://github.com/metr/metr-mobile.git
cd metr-mobile
npm install
```

### 3. Read Documentation

- [README.md](../README.md)
- [CONTRIBUTING.md](../CONTRIBUTING.md)
- [DEVELOPMENT.md](DEVELOPMENT.md)
- [ARCHITECTURE.md](ARCHITECTURE.md)

### 4. Setup IDE

Рекомендуемые настройки:
- VS Code с расширениями:
  - ESLint
  - Prettier
  - React Native Tools
  - TypeScript

### 5. Run Project

```bash
npm start
npm run ios    # или
npm run android
```

## Team Communication

### Channels
- **Discord**: Основной канал коммуникации
- **Email**: Для формальных вопросов
- **GitHub Discussions**: Для технических обсуждений

### Meetings
- **Daily Standup**: Каждый день в 10:00
- **Sprint Planning**: Каждые 2 недели
- **Retrospective**: В конце спринта

## Getting Help

### Questions?
- Спросите в Discord
- Создайте Discussion на GitHub
- Напишите на support@metr.app

### Stuck?
- Проверьте документацию
- Поищите в Issues
- Спросите команду

## Next Steps

4. Создайте PR
5. Получите feedback
