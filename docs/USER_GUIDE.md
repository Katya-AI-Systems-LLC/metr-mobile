# METR User Guide

## Welcome to METR!

METR - это AI-powered платформа для командной продуктивности нового поколения.

## Getting Started

### First Launch

1. **Sign Up / Sign In**
   - Создайте аккаунт или войдите
   - Настройте профиль

2. **Onboarding**
   - Пройдите интерактивный тур
   - Настройте предпочтения

3. **Join Team**
   - Присоединитесь к команде
   - Или создайте новую

## Tips & Tricks

### Keyboard Shortcuts

- `Cmd/Ctrl + K` - Quick search
- `Cmd/Ctrl + N` - New message
- `Cmd/Ctrl + /` - Command palette

### Gestures

- **Swipe right** - Back
- **Swipe left** - Forward
- **Long press** - Context menu
- **Pinch** - Zoom

### Voice Commands

Say "Hey METR" to activate voice assistant:
- "Show my tasks"
- "Start meeting"
- "Send message to [name]"

## Troubleshooting

### App won't start

1. Restart the app

3. Reinstall if needed

1. Check internet connection
2. Force sync
3. Contact support

### Performance

1. Close other apps
2. Clear cache
3. Update app
