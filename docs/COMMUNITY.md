# Community Guide для METR

## Overview

Руководство по участию в сообществе METR.

## Ways to Contribute

### Code
- Fix bugs
- Add features
- Improve performance
- Write tests

### Documentation
- Fix typos
- Improve clarity
- Add examples
- Translate

### Design
- UI/UX improvements
- Icons and graphics
- Branding

### Community
- Answer questions
- Help newcomers
- Organize events
- Write blog posts

## Communication Channels

### Discord
- **Purpose**: Real-time chat
- **Link**: https://discord.gg/metr
- **Rules**: Be respectful, stay on topic

### GitHub Discussions
- **Purpose**: Technical discussions
- **Link**: https://github.com/metr/metr-mobile/discussions

### Email
- **Purpose**: Formal communication
- **Address**: community@metr.app

## Code of Conduct

### Principles
- Be respectful
- Be inclusive
- Be constructive
- Be professional

### Enforcement
- Warnings for minor violations
- Temporary ban for repeated violations
- Permanent ban for severe violations

## Recognition

### Contributors
- Listed in CONTRIBUTORS.md
- Featured in release notes
- Special Discord role

### Top Contributors
- Monthly recognition
- Special badges
- Priority support

## Events

### Meetups
- Monthly virtual meetups
- Quarterly in-person events
- Annual conference (planned)

### Hackathons
- Quarterly hackathons
- Prizes for winners
- Recognition for participants
