# METR Glossary

## Terms and Definitions

### AI Terms
- **AI Assistant**: Искусственный интеллект помощник
- **Smart Replies**: Умные ответы, генерируемые AI
- **Emotion Analysis**: Анализ эмоций и настроения
- **Digital Twin**: Цифровой двойник команды

### Web3 Terms
- **NFT**: Non-Fungible Token, уникальный токен
- **DAO**: Decentralized Autonomous Organization
- **DeFi**: Decentralized Finance
- **Blockchain**: Блокчейн, распределенный реестр

### AR/VR Terms
- **Spatial Audio**: Пространственное аудио
- **Holographic Meeting**: Голографическая встреча
- **Virtual Office**: Виртуальный офис
- **AR Annotations**: AR аннотации

### Development Terms
- **CI/CD**: Continuous Integration/Continuous Deployment
- **Pipeline**: Конвейер сборки и деплоя
- **Artifact**: Артефакт сборки (APK, IPA)
- **Runner**: Сервер для выполнения CI/CD задач

### Git Terms
- **PR**: Pull Request
- **MR**: Merge Request
- **Branch**: Ветка разработки
- **Tag**: Тег версии
- **Commit**: Коммит изменений

### Platform Terms
- **GitHub**: Git платформа от Microsoft
- **GitLab**: Git платформа с CI/CD
- **Bitbucket**: Git платформа от Atlassian
- **Gitea**: Легковесная Git платформа

## Abbreviations

- **METR**: Modern Enterprise Team Revolution
- **API**: Application Programming Interface
- **UI**: User Interface
- **UX**: User Experience
- **SDK**: Software Development Kit
- **CLI**: Command Line Interface
- **IDE**: Integrated Development Environment

## Acronyms

- **ZK**: Zero-Knowledge
- **P2P**: Peer-to-Peer
- **E2E**: End-to-End
- **QA**: Quality Assurance
- **PM**: Project Manager
- **DevOps**: Development Operations
