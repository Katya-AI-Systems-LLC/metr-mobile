## 🚀 Migration Guide

### From v2.0.0 to v2.1.0

1. **Update dependencies**: Run `npm install`
2. **Initialize platform features**:
   ```typescript
   // iOS
   import IOSPlatformFeatures from './app/mobile/ios/IOSPlatformFeatures';
   await IOSPlatformFeatures.getInstance().initialize();
   
   // Android
   import AndroidPlatformFeatures from './app/mobile/android/AndroidPlatformFeatures';
   await AndroidPlatformFeatures.getInstance().initialize();
   ```
3. **Enable Force Touch** (iOS):
   ```typescript
   import ForceTouchHandler from './app/ui/ForceTouchHandler';
   ForceTouchHandler.getInstance().setupDefaultPreviews();
   ```
