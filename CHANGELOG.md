# Changelog

Все значимые изменения в проекте METR будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [2.2.0] - 2024-12-19

### Added
- Полная кастомизация UI компонентов (40+ компонентов)
- Система типографики с градиентами и анимациями
- Particle эффекты для фонов
- Кастомные вибрации и звуки
- Система уведомлений с брендингом
- Экраны профиля и настроек
- Кастомные графики и аналитика
- Система жестов
- Дополнительные темы (Purple, Teal, Pink, Dark Purple, High Contrast)
- Onboarding flow
- Кастомные иконки

### Changed
- Улучшена система брендинга
- Обновлены все UI компоненты
- Оптимизированы анимации

### Fixed
- Исправлены проблемы с кастомизацией
- Улучшена производительность UI

---

## [2.1.0] - 2024-12-18

### Added
- Полный ребрендинг в METR
- Обновлены все платформенные конфигурации
- Новые иконки и splash screens
- Обновлена цветовая палитра
- BrandingManager для централизованного управления брендом

### Changed
- Название приложения: Mattermost → METR
- Package IDs обновлены на com.metr.app
- URL schemes обновлены на metr://

## Типы изменений

- `Added` - новые функции
- `Changed` - изменения в существующей функциональности
- `Deprecated` - функции, которые скоро будут удалены
- `Removed` - удаленные функции
- `Fixed` - исправления багов
- `Security` - исправления уязвимостей
